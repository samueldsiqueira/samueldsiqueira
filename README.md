I build web systems and process automation end to end — from requirements analysis to implementation, integration and support. Most of my work today is in **corporate education platforms**, **simulators and virtual labs for learning**, and **AI agents applied to real workflows** rather than demos.

## 🧭 What I do

- **Systems analysis** — turning vague requirements into specifications a developer can implement without guessing
- **Integrations** — making platforms, APIs and legacy systems talk to each other
- **Automation** — Python/JS routines and scrapers that remove repetitive manual work
- **AI agents** — embedding agents into processes that already exist

## 🧬 Background

<details>
<summary>How I got here</summary>

<br>

My path into technology started as an MMO player: I found the source code of the game I was playing on a forum, dug into it, and after a lot of reading and testing got my own server running more than once.

From **2014 to 2022 at Indra** I worked as a Technical Support Analyst and, from 2017, as a Level 2 Support Analyst — specialized support for Microsoft software at a multinational with more than 50,000 employees and users across Brazil, Latin America, the US and Europe.

To understand systems from the inside, I took a technology degree in **Systems Analysis and Development at Universidade Candido Mendes** (Feb 2022 – Jul 2024). In parallel, as a **Software Development Intern at TIM Brasil** (2022–2024), I automated repetitive telecom engineering processes with Python and JavaScript, using Playwright and Selenium for web scraping.

Since **November 2024** I've been a Systems Analyst at **SENAI Soluções Digitais**, working on education platforms, integrations and AI-assisted processes.
